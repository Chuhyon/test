# 사장님 인터뷰 계획 (T002)

## 목적

정산·광고비·수수료에 대한 사장님들의 실제 불만과 리포트 니즈를 확인하고,
MVP의 방향을 검증한다.

## 후보 선정 기준

### 필수 조건
- 배달의민족에 현재 입점하여 운영 중인 가게 사장님
- 배민셀프서비스를 직접 사용하는 사장님 (대행 아닌 본인)
- 최소 3개월 이상 배민 운영 경험

### 다양성 확보 (10명 기준)

| 기준 | 목표 분포 | 이유 |
|---|---|---|
| **업종** | 한식 3, 치킨/피자 2, 카페/디저트 2, 분식/기타 3 | 업종별 수수료 체감 차이 |
| **지역** | 서울 4, 수도권 3, 지방 3 | 배달비·광고비 지역차 |
| **매출 규모** | 월 500만 이하 3, 500~2000만 4, 2000만 이상 3 | 매출 구간별 수수료 차등 영향 |
| **배민 경력** | 1년 미만 3, 1~3년 4, 3년 이상 3 | 수수료 정책 변경 체감 |

## 모집 채널

| 채널 | 방법 | 기대 효과 |
|---|---|---|
| 사장님 커뮤니티 | 배민 사장님 카페/밴드에 참여 요청 게시 | 적극적 사장님 확보 |
| 지인 추천 | 팀 내 지인 중 자영업자 연결 | 신뢰 기반 솔직한 피드백 |
| 배민 외식업광장 | 교육/세미나 참석자 대상 섭외 | 배민 활용도 높은 사장님 |
| 세무사/회계사 | 배달업 고객 보유 세무사 경유 | 정산 관련 니즈가 강한 사장님 |

## 인터뷰 구조 (1인당 30~40분)

### Part 1: 현재 상황 파악 (10분)

1. 어떤 가게를 운영하시나요? (업종, 지역, 월 매출 대략)
2. 배민을 얼마나 오래 사용하셨나요?
3. 배민셀프서비스에서 주로 어떤 메뉴를 사용하시나요?
4. 정산내역을 얼마나 자주 확인하시나요?

### Part 2: 정산·수수료 이해도 (10분)

5. 배민에서 차감되는 수수료 항목을 알고 계시나요? (자유 응답 후 확인)
6. 실제 입금액과 예상한 금액이 다른 적이 있으셨나요?
7. 정산내역을 보고 이해하기 어려운 항목이 있으셨나요?
8. 광고비가 매출 대비 몇 %인지 파악하고 계시나요?

### Part 3: 니즈 확인 (10분)

9. 정산·수수료를 한눈에 정리해주는 리포트가 있다면 보시겠어요?
10. 어떤 정보가 가장 궁금하세요? (실질 수수료율 / 광고 효과 / 메뉴별 수익 / 업종 평균 비교)
11. 현재 이 정보를 얻기 위해 어떻게 하시나요? (직접 계산 / 세무사 / 포기)
12. 이런 리포트에 월 얼마까지 내실 의향이 있으세요?

### Part 4: 데이터 제공 의향 (10분)

13. 정산내역 엑셀을 직접 다운로드해서 업로드하는 방식이라면 사용하시겠어요?
14. 업로드가 번거롭다면, 어느 정도까지 괜찮으세요? (월 1회 / 주 1회)
15. 본인 가게 데이터를 분석 목적으로 제공하는 것에 대해 어떻게 생각하세요?
16. 익명화된 업종/지역 평균 벤치마크에 본인 데이터가 포함되는 것은요?

## 기록 및 분석

### 기록 방식
- 인터뷰 동의 하에 녹음 (개인정보 비포함 전사)
- 핵심 응답을 구조화된 시트에 기록

### 분석 항목

| 분석 질문 | 성공 기준 |
|---|---|
| 정산/수수료에 대한 불만이 있는가? | 10명 중 6명 이상 |
| 리포트에 대한 니즈가 있는가? | 10명 중 6명 이상 |
| 파일 업로드 방식을 수용하는가? | 10명 중 5명 이상 |
| 유료 전환 의향이 있는가? | 10명 중 3명 이상 |

## 일정

| 단계 | 기간 | 산출물 |
|---|---|---|
| 후보 리스트 작성 | D+1 ~ D+3 | 후보 10~15명 연락처 |
| 인터뷰 일정 확정 | D+3 ~ D+5 | 10명 확정 |
| 인터뷰 진행 | D+5 ~ D+14 | 녹음 + 기록 시트 |
| 인터뷰 요약 | D+14 ~ D+16 | 인터뷰 요약 문서 |

> **주의:** 인터뷰 시 사장님의 배민 ID/PW, 실제 매출 금액, 개인정보를
> 기록하지 않는다. 매출은 "월 500만 이하 / 500~2000만 / 2000만 이상" 등
> 구간으로만 기록한다.
