# 배민셀프서비스 데이터 소스 맵

## 개요

배민 사장님이 셀프서비스(self.baemin.com) 및 사장님 앱을 통해
직접 확인/다운로드할 수 있는 데이터를 맵핑한 문서.

> **조사 방법:** 배민 외식업광장 가이드, 우아한형제들 기술블로그, 세무 도구 연동 사례,
> 배민 수수료 관련 공개 자료를 교차 분석.
> 실제 화면 확인은 사장님 계정이 필요하므로 파일럿(T024) 단계에서 보완한다.

## 1. 셀프서비스 주요 메뉴 구조

배민셀프서비스는 총 23개 메뉴바로 구성되어 있으며, 주요 카테고리는 다음과 같다.

### 1.1 정산·주문 관련

| 메뉴 | 주요 데이터 | 다운로드 | MVP 활용 |
|---|---|---|---|
| **정산내역** | 일별 정산금액, 결제금액, 수수료, 공제금액, 입금예정액 | 엑셀 다운로드 가능 | **핵심** |
| **부가세 신고자료** | 매출구분, 매출, 부가세, 합계 (매출/매입 분리) | 조회·다운로드 가능 | 핵심 |
| **주문내역** | 주문번호, 주문일시, 메뉴, 주문금액, 결제방식 | 조회 가능 (다운로드 여부 파일럿에서 확인) | 참고 |

### 1.2 매출·통계 관련

| 메뉴 | 주요 데이터 | 다운로드 | MVP 활용 |
|---|---|---|---|
| **매출현황 (배민통계)** | 일별·주별·월별 매출, 시간대별 주문, 인기메뉴 순위, 평균 주문금액 | 조회 중심 (다운로드 여부 확인 필요) | 핵심 |
| **주문수·취소수** | 기간별 주문 건수, 취소 건수, 취소 사유 | 조회 중심 | 참고 |

### 1.3 광고 관련

| 메뉴 | 주요 데이터 | 다운로드 | MVP 활용 |
|---|---|---|---|
| **광고 관리** | 오픈리스트, 울트라콜 등 광고 상품별 설정·상태 | 조회 | 참고 |
| **광고 성과** | 광고 상품별 노출수, 클릭수, 주문수, 광고비 | 조회 (다운로드 여부 확인 필요) | 핵심 |

### 1.4 메뉴 관련

| 메뉴 | 주요 데이터 | 다운로드 | MVP 활용 |
|---|---|---|---|
| **메뉴 관리** | 메뉴명, 가격, 카테고리, 옵션, 사진, 영업시간 | 편집 화면 (다운로드 없음) | 2차 |
| **메뉴별 판매** | 메뉴별 판매수량, 매출 | 조회 (다운로드 여부 확인 필요) | 핵심 |

### 1.5 리뷰 관련

| 메뉴 | 주요 데이터 | 다운로드 | MVP 활용 |
|---|---|---|---|
| **리뷰 관리** | 리뷰 목록, 별점, 리뷰 내용, 사장님 댓글 | 조회 중심 | 2차 |
| **리뷰 통계** | 별점 평균, 리뷰 수 추이 | 조회 | 2차 |

### 1.6 가게 정보

| **배달 지역 설정** | 배달 가능 지역, 배달비 설정 | 편집 화면 | 참고 |

## 2. 정산 항목 상세 구조

배민 정산 시 차감되는 항목 구조는 다음과 같다.

### 2.1 수수료 항목 (2025~2026년 기준)

| 항목 | 비율/금액 | 적용 기준 | 비고 |
|---|---|---|---|
| **중개이용료 (배달)** | 6.8% (VAT 별도) | 음식값 기준 | 2025년 기존 점주까지 확대 적용 |
| **중개이용료 (포장)** | 6.8% (VAT 별도) | 음식값 기준 | 2025년 4월부터 적용 |
| **결제수수료** | 약 1.5~3% | 카드/페이 결제 시 | PG사별 상이 |
| **배달비 (업주 부담분)** | 1,900~3,400원/건 | 배달 건당 | 상생협의체 합의 기준 |
| **광고비** | 상품별 상이 | 울트라콜: 월정액, 오픈리스트: 건당 과금 | 별도 정산 |

### 2.2 매출 구간별 차등 수수료 (상생협의체 합의안)

| 월 매출 구간 | 중개이용료율 | 비고 |
|---|---|---|
| 소규모 (하위 구간) | 2.0% | 상생협의체 제안 기준 |
| 중규모 | 중간 요율 적용 | 구간 세부사항 파일럿에서 확인 |
| 대규모 (상위 구간) | 최대 7.8% | 상생협의체 제안 기준 |

> 실제 적용 여부와 구간 기준은 배민 내부 정책에 따라 다를 수 있음.
> 파일럿 가게의 실제 정산 데이터로 검증 필요.

### 2.3 정산 계산 공식

```
실입금액 = 총주문금액 - 중개이용료 - 결제수수료 - 배달비(업주부담) - 광고비 - 기타공제
실질 수수료율 = (총주문금액 - 실입금액) / 총주문금액 × 100
```

### 2.4 정산 주기

- 영업일 기준 D+3~4일 후 입금
- 매월 정산내역 및 부가세 신고자료 제공

## 3. 다운로드 가능 파일 유형 (확인된 것)

| 자료 | 파일 형식 | 경로 | 확인 상태 |
|---|---|---|---|
| 정산내역 | 엑셀 (xlsx/xls) | 셀프서비스 > 정산·주문 > 정산내역 > 엑셀 다운로드 | 확인됨 |
| 부가세 신고자료 (매출) | 조회/다운로드 | 셀프서비스 > 정산·주문 > 부가세 신고자료 | 확인됨 |
| 부가세 신고자료 (매입) | 조회/다운로드 | 동일 경로 | 확인됨 |
| 매출현황 통계 | 화면 조회 | 셀프서비스 > 배민통계 | 다운로드 가능 여부 미확인 |
| 광고 성과 | 화면 조회 | 셀프서비스 > 광고 관리 | 다운로드 가능 여부 미확인 |

## 4. 외부 연동 사례 (참고)

| 서비스 | 연동 방식 | 데이터 범위 | 비고 |
|---|---|---|---|
| **HYPHEN** | 상용 API (스크래핑 기반 고지) | 매출, 정산, 주문, 리뷰, 메뉴 | 유료, 사장님 동의 필요 |
| **아이퀘스트** | 사장님 직접 엑셀 업로드 | 매출내역 | 수동 업로드 방식 사례 |
| **비즈넵** | 부가세 신고자료 연동 | 매출/매입 | 세무 목적 |

## 5. 파일럿에서 확인 필요 항목

- [ ] 정산내역 엑셀의 정확한 컬럼 구성 (필드명, 데이터 타입)
- [ ] 매출현황/배민통계의 엑셀 다운로드 가능 여부
- [ ] 광고 성과의 엑셀 다운로드 가능 여부
- [ ] 메뉴별 판매자료의 다운로드 가능 여부
- [ ] 주문내역의 다운로드 가능 여부 및 포함 필드
- [ ] 매출 구간별 차등 수수료가 실제 정산에 적용되는지 확인
- [ ] 리뷰 통계의 데이터 범위 (기간 제한 등)
