# 메시지 원칙 (T004)

## 핵심 포지셔닝

> "사장님이 제공한 **내 가게 데이터**를 쉽게 설명해주는 정산 리포트"

## 메시지 프레임

| 구분 | 좋은 프레임 | 나쁜 프레임 |
|---|---|---|
| 제품 정의 | 사장님 데이터 분석 도구 | 배민 스크래퍼 / 크롤러 |
| 수집 방식 | 사장님이 직접 제공한 정산 자료를 분석 | 배민에 몰래 접속해서 데이터를 긁어옴 |
| 가치 제안 | 복잡한 정산을 한눈에 이해 | 배민이 숨긴 데이터를 까발림 |
| 수수료 설명 | 정산 구조를 투명하게 설명 | 배민의 과도한 수수료를 폭로 |
| 광고비 설명 | 광고 효과를 객관적으로 분석 | 광고비를 뜯기고 있다는 것을 증명 |
| 벤치마크 | 업종/지역 평균과 내 가게를 비교 | 배민이 차별적으로 수수료를 매기는 증거 |

## 금지 표현

아래 표현은 어떤 채널(웹사이트, SNS, 광고, 보도자료)에서도 사용하지 않는다.

| 금지 표현 | 이유 | 대안 |
|---|---|---|
| "배민이 숨긴 데이터" | 배민을 공격하는 뉘앙스, 분쟁 유발 | "사장님 정산 데이터를 쉽게 정리" |
| "배민 몰래 수집" | 불법 스크래핑 인상 | "사장님이 직접 제공한 자료를 분석" |
| "수수료 폭로" | 공격적 캠페인 도구 인상 | "수수료 구조를 투명하게 설명" |
| "배민의 거짓말" | 명예훼손 리스크 | 사용 금지 (대안 없음) |
| "피해 사장님" | 피해자 프레임은 분쟁 촉발 | "정산이 궁금한 사장님" |
| "강탈 / 착취 / 갈취" | 극단적 표현, 법적 리스크 | "차감 항목", "수수료 구조" |
| "자동 수집 / 스크래핑" | 약관 위반 인상, 기술 리스크 | "사장님이 업로드한 자료" |
| "무료로 까발려 드립니다" | 선정적, 분쟁 유발 | "정산 리포트를 만들어 드립니다" |

## 권장 표현

### 제품 소개 시

```
"사장님이 다운로드한 정산 자료를 업로드하면,
수수료·광고비·실입금액을 한눈에 정리해 드립니다."
```

### 수수료 설명 시

```
"이번 달 총 주문금액 중 실제로 사장님 계좌에 입금된 금액은 OO%입니다.
중개이용료, 결제수수료, 배달비, 광고비가 각각 얼마씩 차감되었는지 확인해 보세요."
```

### 광고 효과 설명 시

```
"이번 달 광고비 OO만원으로 추정 주문 OO건이 발생했습니다.
광고비 1만원당 매출 변화를 확인해 보세요."
```

> 광고 효과는 "인과관계"가 아닌 "상관관계/추정"으로 표현한다.

### 벤치마크 설명 시

```
"같은 업종·지역 사장님들의 평균 실질 수수료율은 OO%입니다.
내 가게와 비교해 보세요."
```

## 톤 앤 매너

| 항목 | 기준 |
|---|---|
| 말투 | 존댓말, 사장님 호칭 사용 |
| 태도 | 중립적·객관적. 배민을 공격하지도, 옹호하지도 않음 |
| 수치 표현 | 계산식과 근거를 함께 표시 ("중개이용료 6.8% × 주문금액 = OO원") |
| 불확실성 | 추정치는 "약", "추정", "참고용"으로 명시 |
| 비교 | "높다/낮다" 대신 "평균 대비 OO% 차이" 등 객관적 표현 |

## 채널별 적용

| 채널 | 핵심 메시지 | 주의사항 |
|---|---|---|
| 랜딩 페이지 | "내 가게 정산, 한눈에 이해하기" | 금지 표현 미사용 확인 |
| SNS/블로그 | "이번 달 실질 수수료율 몇 %인지 아세요?" | 선정적 제목 금지 |
| 사장님 커뮤니티 | "정산 자료 올리면 리포트 만들어 드려요" | 스크래핑/자동수집 언급 금지 |
| 보도자료 | "사장님 동의 기반 정산 투명화 서비스" | 법무 검토 후 배포 |
