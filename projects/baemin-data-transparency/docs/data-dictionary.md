# 수수료·정산 항목 사전 (T012)

## 목적

배민 정산에서 등장하는 수수료·차감 항목의 표준 용어를 정의하고,
각 항목의 계산식을 문서화한다.

## 1. 표준 수수료 유형 (fee_type)

settlement_fee_items.fee_type에 사용되는 표준 코드.

### 1.1 중개이용료 계열

| fee_type | 표준 명칭 | 배민 원본 명칭 (예시) | 설명 | 계산식 |
|---|---|---|---|---|
| `mediation_fee_delivery` | 배달 중개이용료 | 중개이용료, 주문중개수수료 | 배달 주문에 대한 플랫폼 수수료 | 음식값 × 6.8% (VAT 별도) |
| `mediation_fee_pickup` | 포장 중개이용료 | 포장 중개이용료 | 포장 주문에 대한 플랫폼 수수료 | 음식값 × 6.8% (VAT 별도) |
| `mediation_fee_vat` | 중개이용료 부가세 | 부가세 | 중개이용료에 대한 VAT | 중개이용료 × 10% |

### 1.2 결제수수료 계열

| fee_type | 표준 명칭 | 배민 원본 명칭 (예시) | 설명 | 계산식 |
|---|---|---|---|---|
| `payment_fee` | 결제수수료 | 결제수수료, PG수수료 | 카드/페이 결제 시 PG사 수수료 | 결제금액 × 1.5~3.0% |
| `payment_fee_vat` | 결제수수료 부가세 | - | 결제수수료 VAT | 결제수수료 × 10% |

### 1.3 배달비 계열

| fee_type | 표준 명칭 | 배민 원본 명칭 (예시) | 설명 | 계산식 |

| `delivery_fee_customer` | 배달비 (고객 부담) | 배달팁 | 고객이 결제한 배달비 (업주 수입) | 가게 설정 금액 |
| `delivery_fee_subsidy` | 배달비 지원금 | 배달비 지원 | 플랫폼 배달비 보조 | 프로모션별 상이 |

| `ad_other` | 기타 광고비 | 기타 광고 | 기타 광고 상품 | 상품별 상이 |

## 2. 정산 계산 공식

### 2.1 기본 정산 공식

```
총 주문금액 (gross_sales)
  = Σ (완료된 주문의 음식값 + 고객 배달비)

총 차감액 (total_deductions)
  = 중개이용료 + 중개이용료 VAT
  + 결제수수료 + 결제수수료 VAT
  + 배달비(업주부담)
  + 광고비
  + 할인(업주부담)
  + 기타 공제
  - 보전/추가 입금

실입금액 (net_deposit)
  = 총 주문금액 - 총 차감액

실질 수수료율 (effective_fee_rate)
  = (총 주문금액 - 실입금액) / 총 주문금액 × 100
```

### 2.2 항목별 비율 계산

```
중개이용료 비율 = 중개이용료(VAT 포함) / 총 주문금액 × 100
결제수수료 비율 = 결제수수료(VAT 포함) / 총 주문금액 × 100
배달비 비율 = 배달비(업주부담) / 총 주문금액 × 100
광고비 비율 = 광고비 / 총 주문금액 × 100
할인 비율 = 할인(업주부담) / 총 주문금액 × 100
```

### 2.3 광고 ROI 계산 (추정)

```
광고비 1만원당 주문수 = 광고 경유 주문수 / (광고비 / 10000)
광고비 1만원당 매출 = 광고 경유 매출 / (광고비 / 10000)
광고 ROAS = 광고 경유 매출 / 광고비 × 100
```

> 광고 효과는 인과관계가 아닌 상관관계/추정치로 표현한다.

### 2.4 메뉴별 수익성 (원가 입력 시)

```
메뉴별 매출 = 판매수량 × 판매가격
메뉴별 원가 = 판매수량 × 원가
메뉴별 조이익 = 메뉴별 매출 - 메뉴별 원가
메뉴별 마진율 = 메뉴별 조이익 / 메뉴별 매출 × 100
```

### 2.5 전월 대비 변화

```
전월 대비 매출 변화율 = (이번달 매출 - 지난달 매출) / 지난달 매출 × 100
전월 대비 수수료율 변화 = 이번달 실질 수수료율 - 지난달 실질 수수료율
전월 대비 광고비 변화율 = (이번달 광고비 - 지난달 광고비) / 지난달 광고비 × 100
```

## 3. 플랫폼별 용어 매핑

| 표준 용어 | 배민 | 쿠팡이츠 | 요기요 |
|---|---|---|---|
| 중개이용료 | 중개이용료 / 주문중개수수료 | 중개수수료 | 중개이용료 |
| 결제수수료 | 결제수수료 | 결제대행수수료 | PG수수료 |
| 배달비(업주) | 배달비 / 배달대행비 | 배달비 | 배달대행료 |
| 울트라콜 | 울트라콜 | - | 슈퍼리스트 |
| 오픈리스트 | 오픈리스트 | - | - |

> 플랫폼별 매핑 테이블은 새 플랫폼 추가 시 확장.
> 파서에서 원본 명칭(fee_label)을 표준 유형(fee_type)으로 변환한다.

## 4. 주의사항

| 항목 | 주의 |
|---|---|
| VAT 포함/별도 | 배민 중개이용료는 VAT 별도. 비교 시 VAT 포함 기준 통일 |
| 매출 구간별 차등 | 상생협의체 합의안 기준 2.0~7.8% 차등 적용 가능. 실제 적용 여부 파일럿에서 확인 |
| 정산 주기 | D+3~4 영업일. 정산일 ≠ 주문일이므로 기간 매칭 주의 |
| 취소/환불 | 취소 주문의 수수료 환급 여부는 플랫폼별 상이 |
| 소수점 처리 | 금액은 원 단위 반올림, 비율은 소수점 2자리까지 |
