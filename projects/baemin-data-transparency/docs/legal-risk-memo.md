# 배민 약관 리스크 메모 (T005)

## 목적

배달의민족 이용약관에서 본 제품에 영향을 줄 수 있는 조항을 분석하고,
수집 방식별 위험도를 정리한다.

## 1. 관련 약관 조항 분석

### 1.1 자동접속/스크립트/로봇 금지

**배민 이용약관 금지행위 조항:**
> 회사가 제공하지 않는 방법으로 서비스에 접속하는 행위,
> 에이전트(agent), 로봇(robot), 스크립트(script), 스파이더(spider),
> 스파이웨어(spyware) 등의 수단을 제작, 배포, 설치하거나 이를 유도하는 행위

| 위반 가능 행위 | 위험도 | 비고 |
|---|---|---|
| 서버형 자동 로그인 + 데이터 수집 | **매우 높음** | 명시적 금지 대상 |
| 브라우저 자동화 (Selenium/Puppeteer 등) | **높음** | "스크립트" 범주에 해당 가능 |
| 브라우저 확장 프로그램 (현재 보는 페이지만 내보내기) | **중간** | 범위에 따라 해석 가능 |
| 사장님 직접 다운로드 + 업로드 | **매우 낮음** | 약관 저촉 없음 |

### 1.2 서버 부하 야기 금지

> 회사의 서버 및 설비 등에 부하를 야기하는 행위

| 위반 가능 행위 | 위험도 | 비고 |
|---|---|---|
| 대량 API 호출 (수백~수천 건/분) | **높음** | 서버 부하 직접 해당 |
| 소량 API 호출 (수 건/일) | **낮음** | 부하 해당 여부 불명확 |
| 사장님 직접 다운로드 | **없음** | 정상 이용 행위 |

### 1.3 제3자 정보 제공 금지

> 업주는 "서비스" 이용과정에서 습득한 "회사" 및 "서비스",
> "이용자"와 관련한 정보를 제3자에게 제공하거나 외부에 유출할 수 없으며,
> 개인정보의 경우 관련법령에 따라 필요한 보호 조치 등을 취해야 합니다.

| 행위 | 위험도 | 분석 |
|---|---|---|
| 사장님이 **자기 가게** 정산 데이터를 제3자(본 서비스)에 제공 | **낮음~중간** | 본인 데이터이나 약관상 "습득한 정보"에 해당할 수 있음 |
| 사장님이 **고객 개인정보**를 제공 | **높음** | 개인정보보호법 위반 + 약관 위반 |
| 서비스가 개별 가게 데이터를 외부 공개 | **높음** | 약관 + 신뢰 훼손 |
| 익명 집계 벤치마크 공개 | **낮음** | 개별 가게 식별 불가 시 해당 여부 낮음 |

### 1.4 기타 관련 조항

| 조항 | 내용 | 본 서비스 영향 |
|---|---|---|
| 계정 공유/위임 금지 | 타인에게 계정 접근 권한을 부여하는 행위 금지 가능 | ID/PW를 서비스에 제공하는 행위는 위반 소지 |
| 서비스 정상 운영 방해 금지 | 기타 서비스의 정상적인 운영을 방해하는 행위 | 자동화 행위의 포괄적 금지 근거 |

## 2. 수집 방식별 위험도 종합

| 수집 방식 | 약관 위험도 | 법적 위험도 | 운영 위험도 | 권장 | 비고 |
|---|---|---|---|---|---|
| **A. 수동 업로드** | 매우 낮음 | 매우 낮음 | 낮음 | **1순위 (MVP)** | 사장님 자발적 행위 |
| **B. 상용 API (HYPHEN 등)** | 낮음 | 낮음~중간 | 중간 | 검토 | API 사업자가 약관/법무 리스크 부담, 단 우리 측 동의 확보 필요 |
| **C. 브라우저 확장 (현재 페이지만)** | 중간 | 중간 | 중간 | MVP 이후 | "스크립트" 범주 해당 가능, 법무 검토 필수 |
| **D. 서버형 자동 로그인** | **매우 높음** | **높음** | 높음 | **금지** | 약관 명시적 위반, 정보통신망법 위반 가능 |
| **E. 비공개 API 역공학** | **매우 높음** | **매우 높음** | 매우 높음 | **금지** | 약관 위반 + 부정경쟁방지법 위반 가능 |

## 3. 관련 법률 리스크

### 3.1 정보통신망법

- 정당한 접근 권한 없이 정보통신망에 침입하는 행위 금지 (제48조)
- 사장님 본인의 계정을 사장님의 동의 하에 사용하더라도, 약관에서 금지한 방식으로
  접근하면 "정당한 접근 권한"이 아닐 수 있음

### 3.2 부정경쟁방지법

- 타인의 상당한 투자나 노력으로 만들어진 성과 등을 부정한 수단으로 사용하는 행위 금지 (제2조 제1호 파목)
- 대법원 판례: 약관 위반 + 기술적 보호조치 우회 시 부정경쟁행위 인정 가능

### 3.3 개인정보보호법

- 사장님 동의가 있더라도 고객(주문자) 개인정보는 별도 법적 근거 필요
- 수집 목적 외 이용 금지 (제18조)

## 4. 결론 및 권장사항

| 결론 | 설명 |
|---|---|
| MVP는 수동 업로드 방식만 사용 | 약관·법적 리스크가 거의 없음 |
| 서버형 자동 로그인은 원천 금지 | 약관 명시적 위반 + 법적 리스크 높음 |
| 상용 API는 별도 법무 검토 후 도입 | API 사업자의 법적 지위·동의 구조 확인 필요 |
| 브라우저 확장은 MVP 검증 후 법무 검토 | 약관 해석에 따라 리스크 존재 |
| 고객 개인정보는 절대 수집하지 않음 | 약관 + 개인정보보호법 이중 리스크 |
| 제3자 정보 제공 조항 대응 | 사장님 "본인 데이터"의 분석 위탁 구조로 설계 |
