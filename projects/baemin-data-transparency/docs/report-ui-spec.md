# 사장님 리포트 화면 설계 (T022)

## 설계 원칙

- 첫 화면에 핵심 지표 5개 이하
- 사장님이 바로 이해할 수 있는 표현
- 계산식을 확인할 수 있는 "이렇게 계산했어요" 링크
- 경고/이상징후는 눈에 띄게 표시

## 첫 화면: 정산 요약 카드

```
┌──────────────────────────────────────────────────────┐
│  2024년 3월 정산 리포트                    [PDF 다운로드] │
├──────────────────────────────────────────────────────┤
│                                                      │
│  총 주문금액         실입금액           실질 수수료율      │
│  12,500,000원       9,875,000원        21.0%          │
│                                        ▲ 0.3%p 전월比  │
│                                                      │
│  총 차감액           광고비 비율                        │
│  2,625,000원         8.2%                             │
│                                                      │
├──────────────────────────────────────────────────────┤
│  ⚠ 전월 대비 수수료율이 0.3%p 상승했습니다               │
└──────────────────────────────────────────────────────┘
```

## 탭 구성

### Tab 1: 수수료 상세

| 항목 | 금액 | 비율 | 계산식 |
|---|---|---|---|
| 중개이용료 (VAT 포함) | 935,000원 | 7.5% | 음식값 × 6.8% + VAT 10% |
| 결제수수료 | 312,500원 | 2.5% | 결제금액 × 2.5% |
| 배달비 (업주부담) | 850,000원 | 6.8% | 340건 × 2,500원 |
| 광고비 | 527,500원 | 4.2% | 울트라콜 + 오픈리스트 |

→ "이렇게 계산했어요" 접기/펼치기로 각 항목 공식 표시

### Tab 2: 매출 추이

- 일별 매출 막대 그래프 (최근 30일)
- 시간대별 주문 분포 히트맵
- 취소/환불 건수 추이

### Tab 3: 광고 분석

- 광고 상품별 비용/효과 비교
- 광고비 1만원당 추정 주문수
- ROAS (광고 경유 매출 / 광고비)
- ⚠ "광고 효과는 추정치입니다" 표시

### Tab 4: 메뉴 수익성 (원가 입력 시)

- 매출 상위 5개 메뉴
- 마진율 하위 5개 메뉴 (주의 필요)
- 메뉴별 매출/원가/마진 테이블

## 경고 표시 규칙

| 조건 | 표시 |
|---|---|
| 전월 대비 수수료율 0.5%p 이상 변동 | ⚠ 노란 배너 |
| 정산 합계 불일치 (100원 초과) | ⚠ 노란 배너 + 금액 차이 표시 |
| 광고비가 매출의 30% 초과 | 🔴 빨간 배너 |
| 메뉴 마진 음수 | 🔴 해당 메뉴 빨간 하이라이트 |
| 일별 매출 급변 (3배/1/3) | ⚠ 해당일 하이라이트 |
