# 지원 파일 유형 정의 (T017)

## MVP 우선 지원 파일 (2종)

### 1. 배민 정산내역 엑셀

| 항목 | 내용 |
|---|---|
| 출처 | 배민셀프서비스 > 정산·주문 > 정산내역 > 엑셀 다운로드 |
| 형식 | xlsx / xls |
| 예상 컬럼 | 정산일, 주문금액, 중개이용료, 결제수수료, 배달비, 광고비, 기타공제, 입금액 |
| data_category | `settlement` |
| 파서 | `baemin_settlement_parser` |

### 2. 배민 부가세 신고자료

| 항목 | 내용 |
|---|---|
| 출처 | 배민셀프서비스 > 정산·주문 > 부가세 신고자료 |
| 형식 | xlsx / xls |
| 예상 컬럼 | 매출구분, 매출, 부가세, 합계 |
| data_category | `sales` |
| 파서 | `baemin_sales_parser` |

## 2차 지원 파일

| 파일 | 형식 | data_category | 비고 |
|---|---|---|---|
| 배민 광고 성과 | xlsx/csv | `ad` | 화면 캡처 또는 다운로드 |
| 메뉴별 판매 | xlsx/csv | `menu` | 다운로드 가능 여부 파일럿 확인 |

## 파일 자동 감지 로직

```
1. 파일 확장자 확인 (xlsx, xls, csv)
2. 시트명 / 첫 행 컬럼명으로 유형 판별:
   - "정산" 포함 → settlement
   - "매출" OR "부가세" 포함 → sales
   - "광고" 포함 → ad
   - "메뉴" OR "판매" 포함 → menu
3. 판별 불가 시 사장님에게 유형 선택 요청
```

## 파일 제약 조건

| 항목 | 제한 |
|---|---|
| 최대 크기 | 50MB |
| 최대 행 수 | 100,000행 |
| 지원 인코딩 | UTF-8, CP949 (EUC-KR), UTF-16 |
| 지원 확장자 | .xlsx, .xls, .csv |
