# 개인정보 처리 범위 정의 (T006)

## 목적

본 서비스에서 수집/미수집/마스킹 대상이 되는 개인정보 항목을 명확히 구분한다.

## 1. 적용 법령

| 법령 | 주요 조항 | 본 서비스 적용 |
|---|---|---|
| 개인정보보호법 제15조 | 수집·이용 시 정보주체 동의 필요 | 사장님 동의 확보 |
| 개인정보보호법 제17조 | 제3자 제공 시 동의 필요 | 서비스가 제3자에 해당 |
| 개인정보보호법 제21조 | 보유기간 경과·목적 달성 시 파기 | 보관정책에 반영 |
| 개인정보보호법 제26조 | 처리위탁 시 문서화·감독 | 위탁계약 체결 |
| 개인정보보호법 제29조 | 안전성 확보 조치 | 암호화·접근제어 |

## 2. 정보주체 구분

본 서비스에서 관련되는 정보주체는 다음과 같이 구분된다.

| 정보주체 | 설명 | 본 서비스 관계 |
|---|---|---|
| **사장님 (업주)** | 서비스 이용자, 데이터 제공자 | 동의 주체 |
| **주문 고객** | 배민에서 주문한 소비자 | 개인정보 수집 금지 대상 |
| **서비스 운영자** | 본 서비스 운영 팀 | 개인정보처리자 |

## 3. 필드별 처리 방식

### 3.1 사장님(업주) 정보

| 필드 | 수집 여부 | 용도 | 법적 근거 |
|---|---|---|---|
| 사장님 이름 | 수집 (필수) | 서비스 이용자 식별, 리포트 발행 | 동의 (제15조) |
| 연락처 (전화/이메일) | 수집 (필수) | 리포트 발송, 고객지원 | 동의 (제15조) |
| 사업자등록번호 | 수집 (필수) | 가게 소유권 검증 | 동의 (제15조) |
| 가게명/상호 | 수집 (필수) | 리포트 식별 | 동의 (제15조) |
| 가게 주소 | 수집 (선택) | 지역별 벤치마크 분류 | 동의 (제15조), 선택 동의 |
| 배민 ID/PW | **수집 금지** | - | 계정정보 비저장 원칙 |
| 배민 세션 쿠키 | **수집 금지** | - | 계정정보 비저장 원칙 |

### 3.2 가게 운영 데이터

| 필드 | 수집 여부 | 용도 | 비고 |
|---|---|---|---|
| 매출 금액 (일별/월별) | 수집 (동의 시) | 정산 분석 | MVP 핵심 |

| 메뉴명/가격 | 수집 (동의 시) | 메뉴 수익성 분석 | 개인정보 아님 |
| 영업시간 | 수집 (동의 시) | 시간대 분석 | 개인정보 아님 |

### 3.6 리뷰 데이터

| 필드 | 수집 여부 | 처리 방식 | 비고 |
|---|---|---|---|
| 별점 평균/수 | 제한적 수집 (선택 동의) | 통계 집계만 | 2차 |
| 리뷰 키워드 요약 | 제한적 수집 (선택 동의) | 요약만, 원문 미저장 | 2차 |
| 리뷰 원문 | **기본 미수집** | 필요 시 선택 동의 + 재게시 금지 | 저작권 리스크 |
| 리뷰 이미지 | **기본 미수집** | 필요 시 선택 동의 + 재게시 금지 | 저작권 리스크 |
| 리뷰 작성자 정보 | **수집 금지** | 포함 시 마스킹 | 고객 개인정보 |

## 4. 마스킹 처리 기준

파일 업로드 시 아래 패턴에 해당하는 데이터는 자동 마스킹/삭제한다.

| 패턴 | 처리 | 예시 |
|---|---|---|
| 전화번호 (010-XXXX-XXXX) | 마스킹 → 010-****-**** | 010-1234-5678 → 010-****-**** |
| 이름 (한글 2~4자) | 마스킹 → 김** | 김영희 → 김** |
| 주소 (상세주소) | 삭제 | "서울시 강남구 역삼동 123-4 201호" → 삭제 |
| 요청사항 | 전체 삭제 | "문 앞에 놓아주세요" → 삭제 |
| 카드번호 | 삭제 | 1234-5678-9012-3456 → 삭제 |
| 계좌번호 | 삭제 | 110-123-456789 → 삭제 |

> 마스킹 로직은 T018(파일 파서 구현) 단계에서 구현한다.
> 오탐(false positive)보다 미탐(false negative)이 더 위험하므로,
> 의심 데이터는 보수적으로 마스킹/삭제 처리한다.

## 5. 동의 범위별 분류

| 동의 범위 | 포함 데이터 | 필수/선택 |
|---|---|---|
| **정산/수수료 분석** | 정산액, 수수료, 입금액, 차감항목 | 필수 (서비스 핵심) |
| **매출 분석** | 일별 매출, 주문수, 취소수 | 필수 (서비스 핵심) |
| **광고비 분석** | 광고비, 광고 상품, 노출/클릭 | 선택 |
| **메뉴 분석** | 메뉴별 판매량, 가격 | 선택 |
| **리뷰 통계** | 별점, 리뷰 수, 키워드 | 선택 |
| **벤치마크 참여** | 익명 집계 데이터에 본인 가게 포함 | 선택 |
