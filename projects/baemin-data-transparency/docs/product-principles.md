# 제품 프레임: 사장님 동의 기반 데이터 투명화 리포트

## 제품 정의

사장님이 명시적으로 제공한 자기 가게 데이터를 정산·수수료·광고비 관점에서
이해하기 쉽게 분석하는 **동의 기반 데이터 투명화 제품**.

## 제품명 후보

| 후보 | 방향 |
|---|---|
| 가게장부 | 사장님 관점의 정산 분석 도구 |
| 내가게 리포트 | 사장님이 소유한 데이터의 분석 리포트 |
| 정산해줘 | 정산 투명화에 초점을 맞춘 네이밍 |

최종 결정은 사장님 인터뷰(T002) 이후 확정한다.

## 제품 목적

1. 사장님이 배달앱 정산·수수료·광고비 구조를 **스스로 이해**할 수 있게 돕는다.
2. 복잡한 정산 항목을 **한눈에 볼 수 있는 리포트**로 정리한다.
3. 장기적으로 업종/지역별 **익명 벤치마크**를 제공해 합리적 의사결정을 지원한다.

## 제품이 아닌 것 (금지사항)

| 금지 | 이유 |
|---|---|
| 배민 서버에 자동 로그인하는 스크래퍼 | 약관 위반, 법적 리스크 |
| 사장님 ID/PW를 수집·저장하는 서비스 | 계정정보 유출 리스크 |
| 고객 개인정보를 수집하는 서비스 | 개인정보보호법 위반 |
| 배민을 공격하거나 비난하는 캠페인 도구 | 플랫폼 분쟁, 마케팅 리스크 |
| 배민 비공개 API를 호출하는 서비스 | 약관 위반 |

## MVP 범위

### 입력 (사장님이 직접 업로드)
- 배민 정산자료 (엑셀/CSV)
- 주문/매출 자료 (엑셀/CSV)
- 광고비 자료 (엑셀/CSV)
- 메뉴별 판매자료 (엑셀/CSV)

### 출력 (자동 생성 리포트)
| 입력 | 리포트 항목 |
|---|---|
| 정산자료 | 총매출, 실입금액, 총 차감액, 실질 수수료율 |
| 주문/매출 자료 | 일별·시간대별 매출, 취소/환불 패턴 |
| 광고비 자료 | 광고비율, 광고비 1만원당 주문/매출 변화 |
| 메뉴별 판매자료 | 상위 매출 메뉴, 낮은 효율 메뉴, 원가 입력 시 메뉴별 마진 |

### MVP에서 제외
- 리뷰 원문/이미지 분석 (저작권·개인정보 리스크)
- 자동 수집/스크래핑 (약관 리스크)
- 집계 벤치마크 (표본 부족)
- 배민 외 플랫폼 (쿠팡이츠, 요기요 등)

## 핵심 설계 원칙

| 원칙 | 설명 | 반영 방식 |
|---|---|---|
| 명시적 동의 | 사장님이 어떤 데이터를 왜 제공하는지 이해하고 선택 | 데이터 범위별 체크박스 동의 |
| 본인 가게 한정 | 사장님이 권한을 가진 가게 데이터만 처리 | store_id/owner_id 권한 검증 |
| 최소 수집 | 분석에 필요한 데이터만 가져오고 민감정보는 제외 | 개인정보 필드 기본 비수집 |
| 계정정보 비저장 | ID/PW, 세션 쿠키를 서버에 저장하지 않음 | 업로드 기반 MVP |
| 설명 가능성 | 사장님이 계산식을 이해할 수 있어야 함 | 수수료율/광고 ROI 계산식 공개 |
| 개별 비공개 / 집계 공개 | 개별 가게 데이터는 보호, 집계 벤치마크만 공개 | 최소 표본수와 익명화 기준 |

## 수집 방식 우선순위

| 순위 | 방식 | 설명 | 리스크 |
|---|---|---|---|
| 1순위 | 수동 업로드 MVP | 사장님이 직접 다운로드한 파일을 업로드 | 사용성 낮음 |
| 검토 | 상용 API | HYPHEN 등 배달앱 데이터 API 사업자 연동 | 비용/약관 검토 필요 |
| MVP 이후 | 브라우저 내보내기 도우미 | 사장님 브라우저에서 현재 보는 데이터만 내보내기 | 약관 충돌 가능성 |
| 2차 | 집계 벤치마크 | 동의받은 데이터를 익명 집계해 업종/지역 평균 제공 | 재식별 가능성 |

## 성공 판단 기준

| 질문 | 지표 | 성공 기준 |
|---|---|---|
| 사장님이 실제로 문제를 느끼는가? | 인터뷰 빈도 | 10명 중 6명 이상 강한 니즈 |
| 파일 업로드가 가능한가? | 자료 확보 성공률 | 10곳 중 7곳 이상 |
| 리포트를 이해하는가? | 핵심 지표 이해도 | 80% 이상 |
| 리포트가 유용한가? | 반복 사용 의향 | 50% 이상 월 1회 사용 의향 |
| 돈을 낼 의향이 있는가? | 지불 의향 | 30% 이상 유료 전환 가능성 |
