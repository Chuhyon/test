# 리뷰 원문/이미지 취급 정책 (T009)

## 목적

리뷰 데이터의 저작권·개인정보 리스크를 관리하고,
수집/활용 범위를 명확히 한다.

## 1. 리뷰 데이터의 법적 성격

| 데이터 | 법적 성격 | 리스크 |
|---|---|---|
| 리뷰 원문 | 저작물 (저작권법), 개인정보 포함 가능 | 재게시 시 저작권 침해, 개인정보 노출 |
| 리뷰 이미지 | 저작물 (저작권법) | 무단 복제·게시 시 저작권 침해 |
| 별점 | 사실 데이터 (저작물 아님) | 리스크 낮음 |
| 리뷰 작성자 정보 | 개인정보 | 수집 금지 |

## 2. 처리 원칙

### 2.1 기본 원칙: 통계/요약 중심

| 원칙 | 설명 |
|---|---|
| 원문 미저장 | 리뷰 원문을 DB에 저장하지 않는다 |
| 이미지 미저장 | 리뷰 이미지를 서버에 저장하지 않는다 |
| 통계만 수집 | 별점 평균, 리뷰 수, 키워드 빈도 등 집계 데이터만 처리 |
| 재게시 금지 | 리뷰 원문/이미지를 본 서비스에서 타인에게 노출하지 않는다 |

### 2.2 키워드 요약 방식

리뷰 텍스트를 분석하더라도 원문을 저장하지 않고, 추출된 키워드/감성만 보관한다.

```
[리뷰 원문] → [키워드 추출] → [키워드/감성 점수만 저장] → [원문 즉시 삭제]
                                    ↓
                            "맛있다(12회), 배달빠르다(8회), 양많다(5회)"
```

### 2.3 처리 흐름

```
사장님이 리뷰 통계 동의 (선택 동의)
  → 배민셀프서비스에서 리뷰 통계 화면 캡처 또는 수동 입력
  → 별점 평균, 리뷰 수만 기록
  → 키워드 요약이 필요하면 사장님이 직접 입력하거나,
     업로드 파일에서 키워드만 추출 후 원문 삭제
```

## 3. 수집 가능/불가 항목

| 항목 | 수집 가능 여부 | 조건 |
|---|---|---|
| 별점 평균 | 가능 | 선택 동의 |
| 리뷰 수 (일별/월별) | 가능 | 선택 동의 |
| 별점 분포 (1~5점 비율) | 가능 | 선택 동의 |
| 키워드 빈도 (단어만) | 가능 | 선택 동의, 원문 미저장 |
| 감성 분석 결과 (긍정/부정/중립) | 가능 | 선택 동의, 원문 미저장 |
| 리뷰 원문 전체 | **기본 불가** | 사장님 명시적 동의 + 재게시 금지 + 분석 후 즉시 삭제 |
| 리뷰 이미지 | **기본 불가** | 저작권 리스크로 수집하지 않음 |
| 리뷰 작성자 닉네임/ID | **수집 금지** | 개인정보 |
| 사장님 댓글 | 제한적 가능 | 사장님 본인 저작물이므로 동의 시 가능 |

## 4. 리스크별 대응

| 리스크 | 시나리오 | 대응 |
|---|---|---|
| 저작권 침해 | 리뷰 원문을 리포트에 포함하여 재게시 | 원문 미저장 원칙으로 원천 방지 |
| 개인정보 노출 | 리뷰에 고객 이름/전화번호 포함 | 키워드 추출만, 원문 미저장 |
| 명예훼손 | 부정적 리뷰를 가게와 연결하여 공개 | 개별 가게 리뷰 비공개, 통계만 제공 |
| 배민 약관 위반 | 리뷰 데이터의 제3자 제공 | 사장님 본인 가게 통계만, 원문 미제공 |

## 5. MVP vs 2차 범위

| 단계 | 리뷰 데이터 활용 |
|---|---|
| **MVP** | 리뷰 데이터 **미수집**. 정산·매출·광고비에 집중 |
| **2차** | 별점 평균, 리뷰 수, 키워드 요약 (선택 동의) |
| **3차 이후** | 리뷰 추세 분석, 감성 분석 (원문 미저장 전제) |
