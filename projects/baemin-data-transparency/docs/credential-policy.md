# 계정정보 비저장 원칙 (T010)

## 목적

배민 ID/PW와 세션 쿠키를 서버에 저장하지 않는 구조 원칙을 문서화한다.

## 1. 금지 대상

아래 정보는 어떤 형태로든 서버에 저장, 전송, 캐시하지 않는다.

| 정보 유형 | 예시 | 저장 금지 | 전송 금지 | 로깅 금지 |
|---|---|---|---|---|
| 배민 계정 ID | 이메일, 전화번호 | ✅ | ✅ | ✅ |
| 배민 계정 비밀번호 | 평문/해시 모두 | ✅ | ✅ | ✅ |
| 세션 쿠키/토큰 | JSESSIONID, Bearer 토큰 등 | ✅ | ✅ | ✅ |
| OAuth 토큰 | access_token, refresh_token | ✅ | ✅ | ✅ |
| 2FA 인증 코드 | OTP, SMS 인증번호 | ✅ | ✅ | ✅ |

## 2. 원칙

### 2.1 서버 비저장

- 서버(DB, 파일시스템, 환경변수, 로그)에 위 정보를 저장하지 않는다.
- 암호화 저장도 금지한다. 암호화 키 유출 시 평문 노출과 동일하다.

### 2.2 전송 비경유

- 사장님 → 본 서비스 서버 경로로 인증정보를 전송하지 않는다.
- API 요청 파라미터, HTTP 헤더, 폼 데이터 어디에도 포함하지 않는다.

### 2.3 로깅 제외

- 서버 로그 (access log, error log, application log)에 인증정보가 기록되지 않도록 한다.
- 로그 수집 파이프라인에서 인증정보 패턴을 필터링한다.

### 2.4 클라이언트 비전송

- 브라우저 확장이나 클라이언트 앱을 만들더라도, 인증정보를 본 서비스 서버로 전송하지 않는다.
- 로컬에서만 사용하고 서버에 보내는 것은 파싱된 데이터(인증정보 제외)만 허용한다.

## 3. 수집 방식별 적용

| 수집 방식 | 인증정보 관여 | 비저장 원칙 적용 |
|---|---|---|
| **수동 업로드 (MVP)** | 관여 없음 | 원칙 자동 충족 |
| **상용 API (HYPHEN 등)** | API 사업자가 인증 관리 | 본 서비스는 API 키만 관리, 배민 인증정보 비관여 |
| **브라우저 확장** | 사장님 브라우저에서 로컬 처리 | 서버로 인증정보 전송 금지, 데이터만 전송 |
| **서버형 자동 로그인** | 서버에서 로그인 → **원칙 위반** | 이 방식 자체를 금지 |

## 4. 위반 방지 조치

### 4.1 코드 레벨

| 조치 | 설명 |
|---|---|
| 입력 필드 제한 | 회원가입/서비스 UI에 배민 ID/PW 입력란을 만들지 않는다 |
| API 설계 | 배민 인증정보를 받는 API 엔드포인트를 만들지 않는다 |
| 코드 리뷰 | 인증정보를 저장/전송하는 코드는 리뷰에서 거부한다 |
| 정적 분석 | 패스워드/토큰 패턴을 감지하는 린터 규칙 적용 |

### 4.2 인프라 레벨

| 조치 | 설명 |
|---|---|
| 환경변수 | 배민 관련 인증정보를 환경변수에 설정하지 않는다 |
| 시크릿 매니저 | 배민 인증정보를 시크릿 매니저에 저장하지 않는다 |
| 로그 필터링 | 로그 수집 시 인증정보 패턴 자동 마스킹 |

### 4.3 운영 레벨

| 조치 | 설명 |
|---|---|
| 사장님 안내 | "배민 ID/PW를 절대 입력하지 마세요" 안내 문구 상시 표시 |
| 고객지원 | 고객지원 채널에서 배민 인증정보를 요청하지 않는다 |
| 내부 교육 | 운영팀에 비저장 원칙 교육 |

## 5. 사고 대응

만약 의도치 않게 인증정보가 수집된 경우:

```
1. 즉시 해당 데이터 삭제 (DB, 로그, 백업 모두)
2. 해당 사장님에게 통보 + 배민 비밀번호 변경 권고
3. 사고 원인 분석 및 재발 방지 조치
4. 감사 로그에 사고 기록
5. 개인정보보호법에 따른 신고 여부 판단 (72시간 이내)
```

## 6. 점검 체크리스트

정기적으로 (월 1회) 아래 항목을 점검한다.

- [ ] DB에 인증정보 관련 필드/테이블이 존재하지 않는가?
- [ ] API 엔드포인트에 인증정보를 받는 파라미터가 없는가?
- [ ] 서버 로그에 인증정보 패턴이 기록되지 않는가?
- [ ] 고객지원 이력에서 인증정보 수집 사례가 없는가?
- [ ] 코드베이스에 인증정보 저장 로직이 없는가?
