# 개인정보 수집·이용 동의서 초안 (T007)

## 동의서 구조

개인정보보호법 제15조에 따라 아래 사항을 고지하고, 항목별 선택 동의를 받는다.

---

## [필수] 서비스 이용을 위한 개인정보 수집·이용 동의

**수집 주체:** [서비스명] (이하 "회사")

### 1. 수집 항목

| 구분 | 항목 |
|---|---|
| 사장님 정보 | 이름, 연락처(전화번호 또는 이메일), 사업자등록번호, 가게명(상호) |
| 서비스 이용 기록 | 로그인 기록, 파일 업로드 기록, 리포트 생성 기록 |

### 2. 수집·이용 목적

- 사장님 본인 확인 및 가게 소유권 검증
- 리포트 생성 및 발송
- 고객지원 및 문의 처리
- 서비스 개선을 위한 이용 통계 (비식별 처리)

### 3. 보유 및 이용 기간

- 서비스 이용 기간 동안 보유
- 탈퇴 또는 동의 철회 시 **30일 이내 파기**
- 관계법령에 따라 보존이 필요한 경우 해당 기간 보존 (전자상거래법 등)

### 4. 동의 거부 권리

- 위 동의를 거부할 수 있으며, 거부 시 서비스 이용이 제한됩니다.

☐ 동의합니다

## [필수] 가게 정산·매출 데이터 분석을 위한 동의

### 1. 수집 항목

| 구분 | 항목 |
|---|---|
| 정산 데이터 | 정산 금액, 입금 금액, 중개이용료, 결제수수료, 배달비(업주부담), 기타 차감항목 |
| 매출 데이터 | 일별/월별 매출, 주문 건수, 취소 건수, 시간대별 주문 |

### 2. 수집 방법

- 사장님이 배민셀프서비스에서 직접 다운로드한 파일을 본 서비스에 업로드

### 3. 이용 목적

- 정산 구조 분석 및 실질 수수료율 계산
- 매출 추이 분석 및 이상징후 감지
- 사장님 전용 정산 리포트 생성

### 4. 보유 및 이용 기간

- 리포트 생성 완료 후 **원본 파일은 90일 보관 후 자동 삭제**
- 정제 데이터(집계 결과)는 서비스 이용 기간 동안 보관
- 동의 철회 시 원본 파일·정제 데이터·리포트 모두 **30일 이내 삭제**

### 5. 개인정보 포함 시 처리

- 업로드 파일에 **고객 개인정보**(이름, 전화번호, 주소, 요청사항)가 포함된 경우
  자동으로 마스킹 또는 삭제 처리됩니다.
- 마스킹 처리 후에도 식별 가능한 정보가 발견되면 즉시 삭제합니다.

### 6. 동의 거부 권리

- 위 동의를 거부할 수 있으며, 거부 시 정산·매출 리포트 기능을 이용할 수 없습니다.

☐ 동의합니다

## [선택] 광고비 분석을 위한 추가 데이터 동의

### 1. 수집 항목

| 구분 | 항목 |
|---|---|
| 광고 데이터 | 광고 상품별 비용, 노출수, 클릭수, 광고 경유 주문수 |

### 2. 이용 목적

- 광고비 대비 효과(ROI) 분석
- 광고비가 매출에 미치는 영향 추정 리포트 생성

### 3. 보유 기간

- 정산·매출 데이터와 동일한 보관 정책 적용

### 4. 동의 거부 권리

- 위 동의를 거부해도 정산·매출 리포트 기능은 정상 이용 가능합니다.
- 동의 거부 시 광고 ROI 분석 기능만 제한됩니다.

☐ 동의합니다

## [선택] 업종/지역 벤치마크 참여 동의

### 1. 데이터 활용 방식

- 사장님이 제공한 데이터를 **익명화·집계** 처리하여
  업종/지역별 평균 수수료율, 광고비 비율, 실질 마진율 벤치마크에 활용합니다.
- **개별 가게를 식별할 수 없도록** 최소 표본수 기준을 적용합니다.

### 2. 보장 사항

- 개별 가게의 데이터는 어떤 경우에도 외부에 공개되지 않습니다.
- 벤치마크 통계에서 개별 가게가 추정 가능한 경우 해당 데이터를 제외합니다.

### 3. 동의 거부 권리

- 위 동의를 거부해도 모든 기능을 정상 이용할 수 있습니다.
- 동의 거부 시 벤치마크 통계에 본인 데이터가 포함되지 않습니다.

☐ 동의합니다

## 동의 철회 및 데이터 삭제 안내

### 철회 방법

1. 서비스 내 **설정 > 데이터 관리 > 동의 철회** 메뉴에서 철회
2. 고객지원 이메일로 철회 요청

### 철회 시 삭제 범위

| 데이터 유형 | 삭제 시점 | 비고 |
|---|---|---|
| 원본 파일 (업로드한 엑셀 등) | 철회 후 30일 이내 | 복구 불가 |
| 정제 데이터 (파싱·분석 결과) | 철회 후 30일 이내 | 복구 불가 |
| 리포트 데이터 | 철회 후 30일 이내 | 이미 발행된 리포트 포함 |
| 벤치마크 집계 데이터 | 다음 집계 갱신 시 제외 | 이미 발행된 벤치마크에는 포함되어 있을 수 있음 |
| 감사 로그 | 삭제 이력만 보관 (3년) | 관계법령 보존 |

### 삭제 확인

- 삭제 완료 시 사장님에게 **삭제 완료 통지** 발송
- 삭제 이력은 **audit_logs**에 기록
